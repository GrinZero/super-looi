# 语音家居控制优化

「关掉大厅台灯」由 App 在一次语音工具调用内定位开关实体、执行并回读。「关掉第二盏」使用上一轮候选的短引用定位实体。

## 按名称直达和短引用

- 实时语音的 `list_home_devices` 返回名称、房间、状态、分页和短引用。`control_home_device` 接受 `target: { name, room? }` 或 `target: { ref }`，并沿用开关、亮度、色温参数。
- HomeRuntime 在当前连接的目录里按名称、房间和动作能力定位目标。唯一明确匹配可执行，多个明确匹配或只有模糊匹配时由 LOOI 请用户选择。
- 同一语音对话中，名称解析候选与查询结果共享 `d1`、`d2` 等引用。引用绑定到家居连接与实体，语音重连后仍可用，换家居连接后失效。两个入口共用现有控制队列、网关和回读。

## 缩短米家实体 ID

- 保留 `did` 中的小写字母和数字，用 `_u` 加六位十六进制码点转义其余字符。保留米家服务、属性、动作后缀，例如 `light.miot_1083378395_s2`。
- 读取家居缓存时升级旧直连米家实体及快照的 ID。布局继续按原始 `did` 关联，历史回执保留操作当时的 ID。

## 验收

- 配置同时包含开关和模式的大厅台灯，确认语音直达只向开关写入一次并回读。验证同名候选澄清后仅触发选中的实体，切换连接后旧引用零写入。
- 测试米家数字和特殊字符 `did` 及旧缓存迁移。用 `pnpm` 运行语音和家居测试，单独提交语音和米家改动。在横屏真机复验两条语音路径。
