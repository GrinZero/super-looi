# 家居服务绑定新布局与米家视频独立登录 Flow 实施计划

## 1. 背景与目标
根据用户提供的最新 UI 设计图：
1. **服务绑定主页面（图1）**：改造为双栏（Split Layout）主从结构。左栏为“家居服务”列表（米家直连、Home Assistant、离线演示），右栏为选中服务的详情面板（包含服务地区、设备控制分区与同步/启用开关、摄像头视频分区与连接入口）。
2. **官方高清图标资源**：米家官方 Logo 与 Home Assistant 官方 Logo，直接使用官方高清图像资源，不采用手绘。
3. **米家视频独立登录 Flow（图2）**：拆分为独立的登录流程页面，支持多阶段流转：
   - 步骤 1：账号登录（左侧米家 Logo 引导，右侧米家账号、密码与地区）；
   - 步骤 2：图形验证码（按需触发，图形码展示与换一张，错误重试）；
   - 步骤 3：短信/邮箱双重验证（按需触发，验证码输入与倒计时重发）；
   - 步骤 4：完成授权后返回服务绑定页，摄像头状态同步更新为“已授权·已关联 3 台摄像头”，提供“查看摄像头”操作。

## 2. 架构与模块边界设计（遵循 codebase-design）
- **图标与静态资源层 (`apps/nsh/ui/brand-icons.ts`)**：
  提供官方米家与 Home Assistant 的高清 base64 data URI 或本地 Asset 导出，以及规范尺寸的组件封装，避免网络依赖与手绘失真。
- **服务绑定与详情组件 (`apps/nsh/ui/HomeServicesView.tsx` / `HomeSpaceView.tsx`)**：
  - 维持 `store.ts` 作为单一数据源：管理服务启用状态、连接状态、地区、以及新增的视频独立授权状态与流程；
  - 视图层将原有单列滚动重构为响应式双栏主从布局（宽屏/横屏并列，窄屏自适应）；
  - 米家详情内明确拆分“设备控制”与“摄像头视频”两大能力卡片。
- **米家视频独立登录流程组件 (`apps/nsh/ui/XiaomiVideoLoginFlow.tsx`)**：
  - 单独页面/流程状态机：`credentials` -> `captcha` -> `two_factor` -> `done`；
  - 拥有完整的顶部导航（返回、连接米家视频、取消）和左右结构引导与表单；
  - 状态流转契约清晰，可独立在测试中驱动与验证。
