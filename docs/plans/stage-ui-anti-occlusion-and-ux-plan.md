# 横屏首屏舞台（MorphableStage）防遮挡与交互优化方案

## 1. 问题诊断（基于 `844 × 390 pt` 横屏真机视口）

对照实机横屏（`iPhone 16e · 844 × 390 pt`，横屏安全区 `safeLeft = 59`、`safeRight = 59`、`safeBottom = 21`，有效可用宽高 `726 × 369 pt`）与当前源码，三张实测截图暴露出四类结构性遮挡与层级冲突：

## 2. 关键架构取舍（Design-It-Twice）

### 决策 1：活跃舞台（Active Stage）的字幕显示与防遮挡机制

| 方案 | 空间机制与交互职责 | 对 `MorphableStage` 接口与各场景的影响 | 结论 |
| --- | --- | --- | --- |
| **候选 1：给 `PluginStagePresentation` 叠加零散布尔开关** | 新增 `hideVoiceSubtitle`、`dockOffset` 等字段，由插件按阶段自己关闭宿主浮层或加底部留白。 | 接口变成浅模块（Shallow Module），把横屏坐标避让责任泄漏给每个插件；后续新插件若漏配仍会在语音播报时被 Layer 40 盖死。 | **不采用** |
| **方案 A：单源插件内嵌字幕条 + 顶栏居中非阻断轻提示** | 当 `activeStage` 启用且 `hideDefaultDock: true` 时（用户未主动展开 `composeOpen`），宿主 Layer 40 **禁止在底部渲染 `ResponsePreview`**。插件自身台词统一收口到当前可见工作面的头部固定行（发牌卡顶部、抽屉标题副文案或圆桌顶条）；若玩家在白天打开全局语音追问，`transcript` 转写挂载于顶栏下方 `pointerEvents: "none"` 的轻提示胶囊。 | 实现简单、发牌和夜晚结构统一；但在 `split_left` 左右分屏（`36% : 64%`）时，右栏发牌/讨论卡片仍需付出约 `26–32pt` 纵向空间展示长台词。 | **备选** |
| **方案 B（推荐）：姿态自适应具身字幕槽位（Posture-Adaptive Embodied Caption）** | 在继承方案 A「`activeStage` 期间底部 `zIndex: 40` 绝不生成阻断浮层」硬不变量的基础上，根据 `facePosture` 选择最自然的归属位置：<br>1. **`split_left` 左右分屏姿态（发牌、天亮公告、白天发言）**：左栏 `36%`（宽 `254pt`）中 LOOI 表情垂直居于 `y: 56..258`，下方 `y: 264..358` 天然留有约 `94pt` 空白——将法官字幕胶囊直接放在 **LOOI 嘴部正下方**（`pointerEvents: "none"`），形成“LOOI 开口主持”的具身一体感，同时把右侧 `64%` 卡片的纵向空间 100% 释放给操作控件；<br>2. **`floating_top` 悬浮表情姿态（夜晚行动、投票、上警）**：抽屉占满下方工作区，法官台词直接合入抽屉标题栏副文案（及静音/异常角标），零额外浮层。 | 不增加外部抽象，仅利用 `split_left` 左栏现成留白；若玩家触发全局语音追问且当前处于 `floating_top`，转写自动落入顶栏下方非阻断轻胶囊，不与抽屉或表情抢位。 | **推荐** |

### 决策 2：半透明抽屉与底层 `StageCanvas` 的防重影契约

- **现有缺陷**：`StageCanvas`（`zIndex: 10`）与 `StageDrawer`（`zIndex: 25`）独立渲染；当 `StageDrawer` 展开到 `medium / large` 时，半透明玻璃材质（`rgba(14,14,16,0.94)`）透出底层文字，`StageCanvas` 仍在屏幕底部绘制夜间字幕。
- **方案设计**：把遮挡消隐下沉到几何真相源 `computeStageLayout()`（`apps/nsh/ui/stage/posture-geometry.ts`）：
  1. 新增派生字段 `canvasOccludedByDrawer: boolean`（当 `effectiveDetent === "large"` 或 `height - canvasTop - visibleDrawerHeight < 72` 时返回 `true`）；
  2. 当 `effectiveDetent` 为 `peek` 或 `medium` 时，`canvas.bottom = visibleDrawerHeight + 8`，保证画布内容始终位于抽屉顶沿之上，两者垂直严格不相交；
  3. 当 `canvasOccludedByDrawer === true` 时，`MorphableStage` 直接将 `StageCanvas` 设为 `opacity: 0, pointerEvents: "none"`；同时从 `WerewolfStageCanvas` 移除冗余的 `werewolf-night-subtitle` 底部胶囊（由决策 1 的单源槽位替代）。

### 决策 3：矮横屏纵向空间回收与逃生入口去重

- **现有缺陷**：`390pt` 高的视口内，安全顶边 `56pt` + 胶囊 `34pt` + 抽屉拖手条 `36pt` + 底部常驻退出条 `38pt`，有效工作高度被压缩；同时存在 `[× 退出舞台]`（宿主顶栏）、`[终止本局]`、`[退出狼人杀]` 三个常驻退出控件。
- **方案设计**：
  1. **逃生入口职责分离与 LAN 解绑收纳**：宿主顶栏 `[× 退出舞台]` 为全舞台唯一常驻无条件退出入口（回到陪伴主页并支持顶部胶囊断点续玩）；抽屉底部 `werewolf-drawer-resilience-bar` 中的低频动作（`终止本局`、`退出狼人杀`，以及 `lan_companion` 模式下已认领座位的 `#k 解绑` `release_lan_seat`）统一从底栏移除，收纳至抽屉/胶囊右上角 `[⋯]` 上下文菜单（直接复用 `nsh/base` 的 `Menu` 触发原生 `AlertDialog` 确认，无需手写双态定时器）。仅在存在已绑定 LAN 座位时，抽屉头部右侧可并排显示简洁计数徽标提示，点按可经 `[⋯]` 快速解绑。
  2. **抽屉手柄栏瘦身**：`StageDrawer` 顶栏高度由 `36pt` 缩减为 `20pt`，去掉 `border-b` 内部横线，仅保留居中胶囊指示条与右侧折叠按钮，视觉与底层内容一体。
  3. **净收益**：在扣除顶部 `floating_top` 胶囊增高与间距扩大（`+16pt` 让位）后，夜晚 `large` 抽屉内部有效内容净高仍增加约 **`+38pt`**（由 `~203pt` 增至 `~241pt`，来自 `+16pt` 手柄瘦身 `+ 38pt` 移除底栏 `- 16pt` 顶部让位），确保 6–12 人网格按钮在 `44pt` 触控高度下完整展示不裁剪。

## 3. 具体界面与交互规范

### 3.1 顶部宿主栏与 `StageCapsule` 信息层级重构

- **左上角状态指示去歧义**：
  - 当插件通过 `muted_broadcast` 播报台词时，顶栏不再显示误导性的「● 语音已静音」，而是显示插件舞台语义或「● 法官播报中」；在等待玩家操作的纯触控阶段显示「● 桌游主持中」，仅当用户手动关闭麦克风且处于自由对话态时才显示「语音已静音」。
- **`StageCapsule` 紧凑化与触控热区**：
  - **发牌阶段**：不显示未开始的 `第 1 天 | 存活 9/9`，改显 `● 环视发牌 · 已领 0/9` + `[重播]` + `[🔊 播报 / 🔇 静音]` + `[⋯]`，整体高度 `30pt`，横向宽度收窄，不再迫近右侧宿主按钮区；紧凑按钮保留 `hitSlop`（上下 `8pt`、左右 `6pt`）及 `>= 6pt` 水平间距以满足 iOS `44×44pt` 可点击规范。
  - **夜晚/白天阶段**：`● 第1夜 · 女巫睁眼 | 存活 9/9 | [重播] [🔇 静音] [⋯]`；夜晚抽屉顶栏按钮（`[静音]`、`[立即遮蔽]`、`[⋯]`）保持 `min-h-11`（`44pt`）或等效 `hitSlop`。

### 3.2 `floating_top` 表情胶囊防裁切（`posture-geometry.ts`）

- 将 `STAGE_BASE_PILL_HEIGHT` 从 `250` 调整为 `286`，确保 `RobotFace` 含上方挑眉与右上角 `star_sparkle` 星光（`scale = 0.28` 时约 `78–80pt` 包络）完整落在圆角胶囊内部不贴边；
- 保证胶囊顶部 `>= safeTop + 8pt`，胶囊底沿到 `StageDrawer` 顶沿预留 `10pt` 呼吸间隙（替代当前过紧的 `6pt`）。

### 3.3 发牌面板（`DealingStageCard`）去卡套卡与零挤压布局

1. **去卡套卡**：外层保留唯一 `rounded-3xl` 容器（`elevated-glass`），内部取消嵌套的左/右两张大卡片边框，改为 **`1px` 垂直细分隔线** + 清晰的内外间距层级：
   - **左栏（固定 `112pt`）**：`72×72` 镜头对准圆环（已居中时亮翠绿描边）+ `1号玩家` + 状态微字（`请正对镜头`）+ 紧凑 `[抓拍头像]` 按钮（`min-h-11` 确保 `44pt` 触控热区）。
   - **右栏（`flex-1`，宽约 `308pt`）**：顶部座位进度条 `#1..#9` 精简为单行紧凑胶囊；中部为防窥护盾区或亮牌身份卡（仅身份卡保留浅色阵列着色边框）；底部操作栏彻底消除 4 按钮挤压。
2. **发牌底部操作栏简化为最多 3 个动作**：
   - **防窥遮蔽态**：`[← 上一位]`（仅 `canStepBackDeal` 时显示，`shrink-0`）+ `[按住查看底牌]`（`flex-1 min-w-0`，`<Text numberOfLines={1}>`）+ `[记住了，下一位]`（`shrink-0` 仅当当前座已查看过或明确需要跳过时高亮主色）。
   - **亮牌查看态**：**删除重复的 `[遮蔽]` 按钮**（松手即 `0ms` 遮蔽，轻点查看后按钮变为高亮琥珀色 `[点击或松手遮蔽]`），操作栏仍维持最多 3 枚控件，单键最小宽度 `>= 100pt`，结合 `numberOfLines={1}` + `adjustsFontSizeToFit`（英文端同步使用 `"Hold to Peek"` / `"Tap to Hide"` / `"Next"` 简短标签）防止大字号或英文模式溢出。
   - **文案精简**：同步清理发牌卡（`StageCanvas.tsx:291`）与夜间防窥门禁（`StageDrawer.tsx:570`）中的 `"0ms"` 工程术语和单字孤行折行，统一改为「按住查看底牌 · 松手立即遮蔽」。

### 3.4 夜晚抽屉（`NightRoleDrawerPanel`）按钮主次语义与热区

- **禁用态不再抢占主按钮视觉焦点**：
  - 图 3 中当女巫解药已用尽（`canSave = false`）时，不再在最右侧主提交位渲染灰白的实心 `[无法使用解药]` 主按钮；而是将解药信息置于头部状态副文案（`解药已用尽 · 可选座用毒或直接闭眼`），底部仅保留两个真实可操作按钮：
    - **未选毒药座位时**：左侧描边次按钮 `[选座使用毒药]`（禁用态提示先选座），右侧**实心主按钮 `[不用药，闭眼]`**（`bg-eye-core text-stage-bg`），与女巫当前唯一可直接提交的默认动作完全匹配。
    - **选中座位 `#k` 时**：左侧次按钮 `[不用药，闭眼]`（普通描边态），右侧**主提交按钮升级为 `[使用毒药毒 #k]`**（玫瑰红/高亮强调或主提交确认态），一眼明确点击后将执行毒杀。
- **座位网格舒适排布**：得益于释放出的 `~+38pt` 净工作高度，`#1..#9` 九颗选人按钮可保持 `min-h-11`（`44pt`）与合理 `gap-2` 间距，不再贴近顶部或底部边框。

## 5. 动效清单（Motion Inventory）

1. **控件按压态**：所有按钮维持 `active:opacity-75`（`120ms easeOut`）；选座按钮切换选中框使用状态色平滑过渡（`150ms`）。
2. **防窥盾查看 / 遮蔽**：
   - 翻开亮牌：`120ms` 轻微透明度渐入；
   - **松手遮蔽**：**`0ms` 瞬时切换（严格无退出过渡动画）**，防止旁观者余光捕获身份残影（`reduceMotion()` 与常规模式一致保持 `0ms`）。
3. **抽屉遮挡消隐与白天避让动画**：
   - 抽屉升至 `large` 跨越临界阈值时，`StageCanvas` 使用 `150ms` 淡出（`reduceMotion()` 时立即切换为 `0`）；
   - 白天抽屉在 `peek ↔ medium` 间弹簧展开或收起时，`StageCanvas` 底边（`canvas.bottom`）随抽屉可见高度以 `180ms easeOut` 同步过渡（`reduceMotion()` 时立即落位），避免圆桌瞬间跳变。
4. **左栏具身字幕胶囊（方案 B）**：法官语音开始时 `180ms` 上浮 `4pt` + 淡入；结束后保留文本供查看并在切换下一段台词时平滑替换（`reduceMotion()` 仅即时更新文案）。
5. **`[⋯]` 局内操作菜单**：原生 `Menu` 从触发按钮锚点展开/收起；破坏性动作通过原生 `AlertDialog` 二次确认。

## 6. 需要确认的决策项
