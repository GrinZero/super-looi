# 狼人杀环视认座与底座发牌产品目标

LOOI 开局环视一周，帮主持人把桌上的玩家和座号对应起来。底座发牌动作分为三档：纯眼神静止、**普通模式（LOOI 留在桌中央，转向当前玩家）** 与 **进击模式（LOOI 开到当前玩家面前，停稳后领牌）**。开局环视是可选操作，玩家在各模式下都能按明确的座号顺序领牌。

## 模式适用边界与座位图复用

- **本机防窥与手机副屏的分工。** 普通模式与进击模式主要服务于本机顺序领牌；手机副屏（`lan_companion`）由玩家在各自手机上并行领牌，不执行逐席移动递牌。
- **跨阶段复用规则。** 确认后的座位图不仅用于发牌，白天轮流发言可直接复用方向面向当前发言人；黑夜阶段保持随机掩护策略，不按座位图直转神职方向，避免暴露身份方位。

## 开局环视与座位图

1. **指定起点。** 主持人设置玩家人数，让 LOOI 朝向 1 号，然后点「环视认座」。以 9 人局为例，桌面按顺时针依次编号 1–9。
2. **转一圈采集。** LOOI 原地环视，同步记录拍摄时的朝向和画面中的人脸位置。将相邻画面里重复出现的人脸合并，按人脸区域裁剪出清楚的单人头像，按方向排列为候选座位。座位间距可以不同。
3. **看一眼，改得动。** 环形座位图显示座号、单人头像和相对方向。主持人能调换座号、删除误拍的围观者、补拍漏掉的玩家，也能重新指定 1 号。检测人数和设定人数对不上时，先标出待确认项，让主持人定下最终对应关系，再保存座位图。
4. **确认后发牌与缓存复用。** 座位图保留玩家与方向的对应关系，单人头像可做本地缓存复用（与高频对局状态分离，避免每次操作重复序列化大图）。跳过环视时可以直接按屏幕座号领牌。同一桌连开、座位与桌面布置未变时允许复用座位图：主持人把 LOOI 放回桌中对准 1 号执行一次「对齐 1 号」即可整体校正相对方向，换人时只更新对应座位。

## 普通模式 · 在桌中央转向

- 轮到哪一位，屏幕就显示哪个座号，LOOI 从当前朝向转到该座位记录的方向。到附近后，摄像头可用清晰、稳定的人脸做短时小幅调整；一旦收敛稳定、超时或玩家手指触碰屏幕，即锁定并冻结电机。
- 镜头没看到人，或者多人同时入镜难以确定目标，LOOI 停在该座位的方向，屏幕提示「请正对镜头」。玩家可以直接领牌。
- 选择上一位或快速继续切座时，立即结束旧座位的动作，底座以当前实际朝向重新计算到最新座位的转角。领牌期间保持静止；即便按压看牌时底座被轻微碰歪，或玩家临时将手机摘下看牌再吸回底座，发牌流程也不中断，放回后不乱转。
- 普通模式需要的是座位方向。主持人把 LOOI 放在桌中央，领牌时由当前玩家接近屏幕。

## 进击模式 · 开到玩家面前

- 进击模式仅用于本机顺序领牌，在同一张座位图上增加每个座位的**停靠位置**。停靠点应让玩家坐着就能看到屏幕、伸手操作。人脸位置用于确认朝向，停靠位置决定车身开到哪里。
- **分阶段收敛。** 首阶段聚焦「桌中心 ↔ 座位」辐射式往返停靠，先在清空中央区域的桌面上验证重复停靠精度、单次交接耗时和玩家坐姿触达体验；相邻席位直达与障碍绕行作为后续阶段能力，视首阶段实测数据决定。
- 中途发现路线受阻，LOOI 停稳，主持人可以清理路线后继续，也可以把 LOOI 放回桌中央，改用普通模式完成发牌。移动与停靠是进击模式的核心体验，因此开局需确认各席停靠点和桌面可通行区域。

## 两种模式的共同交互

- **座号由游戏决定。** 摄像头和底座跟随当前座位。检测到人脸、底座到位或玩家探头都不会自动确认领牌。
- **交接和操作分时。** 切座即更新屏幕并结束旧座位的动作。底座停稳后，玩家可以按住查看底牌，松手即遮蔽；按住查看期间电机保持冻结。当前座号一直可见，便于主持人知道游戏在等谁。
- **进度由玩家确认。** 主持人可回到上一位，已确认的座位按发牌规则处理。扫出的单人头像用于座位核对；需要更换时，在座位图上补拍或编辑。

## 产品验收

| 场景 | 玩家或主持人能观察到的结果 |
| --- | --- |
| 9 人环视，座位间隔不均匀 | 从指定的 1 号开始顺时针排列，主持人能在同一张图上确认座号与单人裁剪头像。 |
| 一人低头漏拍，或扫到围观者 | 主持人可以单独补拍、移除和调整座号，最终座位图与实际座次一致。 |
| 同一桌连开复用座位图 | 把 LOOI 放回桌中执行一次「对齐 1 号」后即可复用上局座位图，换人只需更新对应座位。 |
| 普通模式从 7 号到 8 号，再回到 7 号 | 横屏真机上的当前座号和底座朝向一致，回退后重新对准 7 号。 |
| 领牌人暂时没入镜、多人同框或快速切人 | 游戏正常推进。底座停在最新座位的方向，旧动作立刻结束，按住看牌时保持静止。 |
| 领牌期间触碰偏转或临时脱座再吸回 | 发牌进度不中断，放回后不乱转，切下一位照常推进。 |
| 进击模式「桌中心 ↔ 座位」连续访问多个座位 | LOOI 能重复停在指定位置，车身面向玩家。玩家坐在原位能看屏幕并完成领牌。 |
| 进击模式的路线临时被挡住 | LOOI 停住，当前座号和领牌进度仍清楚，主持人能清理后继续或切回普通模式。 |
| 跳过环视 | 主持人直接进入按座号发牌，选定的角色和领牌顺序照常生效。 |

## 待真机验证的设计选择

- **普通模式的朝向反馈与视觉自标定。** 现有底座接口只提供开环转向指令，发牌流程尚未读取实际横向转角。先验证手机无磁姿态（重力轴投影偏航角）加摄像头短试探脉冲能否稳定标定不同桌面的起转死区、转向正负号与角速度比例，并测扫完一周后回到指定座位的误差。测量结果决定步进环视与闭环转向的参数。
- **进击模式的移动反馈与桌面安全。** 一次在桌中央环视可以采集各席方向。确定停靠点还需要知道移动距离、桌面边界和可通行路线。先真机验证 `FED9` 悬崖遥测、实验性直行偏置（Trim）标定与基于人脸框尺度的视觉停靠精度，记录到位误差、每次交接耗时及玩家坐着够到屏幕的情况，据此定首版进击模式支持的桌面条件。
