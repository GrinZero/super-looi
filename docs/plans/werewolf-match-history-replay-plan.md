# 狼人杀历史对局与单局复盘

本机与扫码局共用主持设备上的历史记录。正式结算后可立即查看，重启 App 后可从插件设置、大厅或终局打开。界面参考[产品设计](werewolf-match-history-product-design.md)。

## 实施

1. 沿用对局 ID 和插件 SQLite 归档，加入胜负原因、终局座位快照和逐轮记录。列表只读取摘要，详情按 ID 查询。旧记录可打开摘要，旧版恢复局从恢复点续记。
2. 复盘共用整局总结、发牌、白天及夜晚页面。公开名场面跳到对应轮次，夜晚动作逐夜展开，警长、放逐及各次 PK 票型独立保存和查看。
3. 复用终局 AI 点评，以对局 ID 写回结果。立即再开后结果仍归原局，重新生成以最新请求为准。故障保留阶段、错误码及原因。
4. 接通终局直接复盘、大厅和终局历史入口、逐层返回、确认删除。删除最后一条显示空态。停用插件时仍可查看摘要。

## 验收

- 本机与扫码局、立即再开、重启、暂停恢复、旧摘要和归档失败恢复。
- 逐轮核对救人、平安夜、警长票与 PK、放逐票与 PK、弃票及最终结算。
- 延迟点评、生成失败、删除后重启、删除时有未完成点评。
- NSH 类型检查、横屏浅色和深色自动化、横屏真机交互及独立审查。
